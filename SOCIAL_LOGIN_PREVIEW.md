## 🎨 Spacing & Layout

### Button Grid
```
┌────────┐  ┌────────┐  ┌────────┐
│ Google │  │Discord │  │ Apple  │
└────────┘  └────────┘  └────────┘
    ↑           ↑           ↑
    │           │           │
    └───12px────┴───12px────┘
```

**Specifications:**
- Grid: 3 columns, equal width
- Gap: 12px between buttons
- Height: 44px (11 in Tailwind)
- Width: 100% / 3 - gap

### Vertical Spacing
```
[Login Button]
     ↓
   16px
     ↓
[Separator]
     ↓
   16px
     ↓
[Social Buttons]
```

**Specifications:**
- Space between form and separator: 16px
- Space between separator and buttons: 16px
- Total space: 32px + separator height

## 🎨 Animation & Transitions

### Button Hover
```css
transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
```

**Effects:**
- Background color fades in
- Border color changes
- Subtle scale (optional)
- Smooth, professional feel

### Loading State
```css
@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}
```

**Effects:**
- Spinner rotates continuously
- Button becomes disabled
- Opacity reduces to 50%
- Cursor changes to not-allowed
