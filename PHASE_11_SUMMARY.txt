## 🔍 HOW IT WORKS

### Login Flow

1. User enters "john@example.com" or "john_doe"
2. System checks: Does input contain @ and . ?
   - YES → It's an email, use directly
   - NO → It's a username, lookup email
3. If username: Query database for email
4. Authenticate with email using Supabase Auth
5. Success → User logged in
6. Failure → Show appropriate error

### Detection Logic

```typescript
const isEmail = /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(input);

if (!isEmail) {
  // It's a username, fetch email
  const email = await profilesApi.getEmailByUsername(input);
  if (!email) {
    // Username not found
    toast({ title: 'User Not Found', ... });
    return;
  }
}

// Authenticate with email
await supabase.auth.signInWithPassword({ email, password });
```
