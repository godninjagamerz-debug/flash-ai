## 🔐 Password Reset Feature

### When to Use:
- Forgot your password
- Need to reset password
- Can't log in

### How to Use:

#### Step 1: Go to Login Page
- Open Flash AI
- You'll see the login form

#### Step 2: Click "Forgot Password?"
- Look for the link next to "Password" label
- It's in the top-right of the password field
- Click the blue "Forgot Password?" link

#### Step 3: Enter Your Username
- A dialog will appear
- Enter your username (not email)
- Example: If your email is `john@thebestai.com`, enter `john`

#### Step 4: Click "Send Reset Link"
- The button will show a loading spinner
- Wait for confirmation

#### Step 5: Check Your Email
- Email sent to: `{your-username}@thebestai.com`
- Look for "Password Reset" email
- Click the link in the email

#### Step 6: Set New Password
- You'll be redirected to reset page
- Enter your new password
- Confirm the password
- Click "Update Password"

#### Step 7: Log In
- Return to login page
- Use your username and new password
- Click "Sign In"

### Tips:
- ✅ Username must be valid (letters, numbers, underscores only)
- ✅ Check spam folder if email doesn't arrive
- ✅ Reset link expires after 1 hour
- ✅ You can request multiple reset emails

## 🚨 Troubleshooting

### Password Reset Issues:

**Problem:** "Forgot Password?" link not visible
- **Solution:** Make sure you're on the login tab, not signup

**Problem:** Email not received
- **Solution:** Check spam folder, verify username is correct

**Problem:** Reset link doesn't work
- **Solution:** Link may have expired, request new one

**Problem:** Invalid username error
- **Solution:** Use only letters, numbers, and underscores

### Admin Plan Issues:

**Problem:** Admin badge not showing
- **Solution:** Make sure you're logged in as admin user

**Problem:** Plan not activating
- **Solution:** Verify you have admin role in profile

**Problem:** Payment still required
- **Solution:** Check if you're logged in as admin

**Problem:** Can't switch plans
- **Solution:** Log out and log back in as admin

### UI Issues:

**Problem:** Animations not smooth
- **Solution:** Try different browser, clear cache

**Problem:** Gradients not showing
- **Solution:** Update browser to latest version

**Problem:** Blur effects not working
- **Solution:** Check browser supports backdrop-filter
