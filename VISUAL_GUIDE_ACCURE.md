## 12. ✨ Animation Details

### Splash Screen Animations

1. **Fade In** (0.5s)
   - Opacity: 0 → 1
   - Smooth entrance

2. **Scale In** (0.5s)
   - Scale: 0.8 → 1
   - Logo grows

3. **Bounce Slow** (2s loop)
   - Y: 0 → -10px → 0
   - Gentle bounce

4. **Spin Slow** (continuous)
   - Rotation: 0° → 360°
   - Sparkles rotate

5. **Slide Up** (0.6s)
   - Y: 20px → 0
   - Text rises

6. **Slide Up Delayed** (1s)
   - Delayed text animation
   - Subtitle appears

7. **Loading Bar** (2s)
   - Width: 0% → 100%
   - Progress fills

8. **Float** (6s loop)
   - Background dots move
   - Adds life
