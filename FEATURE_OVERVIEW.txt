└──────────────────────────────────────────────────────────────────────────────┘

1️⃣  OAuth System Updates
    Scenario: Migrating authentication providers
    Action: Reset all accounts with explanation message
    Result: Users log in with new system, see notification

2️⃣  System Maintenance
    Scenario: Major database migration or update
    Action: Reset affected accounts after maintenance
    Result: Users get fresh start with preserved profiles

3️⃣  Individual User Request
    Scenario: User wants to start over
    Action: Reset single account with personalized message
    Result: User gets clean slate while keeping plan

4️⃣  Bulk User Management
    Scenario: Reset specific user group (e.g., test accounts)
    Action: Select users and reset with group message
    Result: Selected users reset, others unaffected
